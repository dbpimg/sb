# Privacy — Jack Of Spades Marketing Games Quick Rummy

**Public beta disclosure (October 2026).** This game runs in your browser and does not require an account, email, or payment. Your current game state and score are saved locally using your browser's localStorage so you can resume later. You can erase the save by clearing site data in browser settings or choosing New match to reset gameplay.

The game itself does not currently integrate analytics, advertising SDKs, accounts, multiplayer, or third-party trackers. The website is served on GitHub Pages; GitHub may independently process connection information to operate its hosting service, governed by GitHub's policies. This document does not claim to describe GitHub's independent logging.

If analytics, advertising, accounts, or external integrations are added later, this disclosure must be reviewed and updated **before** that release.

This game is free to play; it does not offer real-money gambling.
